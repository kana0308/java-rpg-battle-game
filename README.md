# Java RPGバトルゲーム

## 概要

Java学習のアウトプットとして開発したコンソール型RPGゲームです。

勇者を操作し、スライム、ゴブリン、ドラゴンと戦いながらレベルアップしていきます。

## 実装機能

- 通常攻撃
- 回復
- 必殺技（使用回数制限あり）
- 経験値システム
- レベルアップ
- 攻撃力上昇
- 敵3体との連続戦闘
- ゲームオーバー判定
- ゲームクリア判定
